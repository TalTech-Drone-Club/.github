# .github

Default issue and pull request templates for every TalTech-Drone-Club repository
that has no templates of its own.

- `.github/ISSUE_TEMPLATE/default.md`: issue with goal, context and links, steps
- `.github/pull_request_template.md`: pull request with what and why, the issue it closes, how to check

A `.github/ISSUE_TEMPLATE` folder in a single repository switches these issue
templates off there, so don't add one. Change these files by pull request.
